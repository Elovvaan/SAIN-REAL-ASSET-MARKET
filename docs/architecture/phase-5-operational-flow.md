# Phase 5 Operational Flow

Counterparty -> authenticated transaction participation window -> participation event -> SRA Counterparty Agent -> exact funding package + Phase 2 reasoning + Phase 4 outcome -> governed case -> persisted response -> counterparty.

If the request is ordinary processing clarification, the response is returned from recorded transaction state. If authoritative data is missing, the response is blocked for context resolution. If a processing exception is reported, the case remains active for corrective reasoning. If the request crosses a reserved authority boundary, the case becomes `AWAITING_AUTHORITY` and the current transaction remains unchanged.
