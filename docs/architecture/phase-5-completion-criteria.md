# Phase 5 Completion Criteria

Phase 5 is complete when the deployed transaction participation flow can: record a counterparty question or processing exception; resolve it against the exact funding package, Phase 2 context, and Phase 4 outcome state; persist an idempotent case and response; return the response through the authenticated participation window; refuse to infer missing authoritative facts; route protected changes and authorizations to `AWAITING_AUTHORITY`; preserve financing and settlement state while exceptions are unresolved; and expose case status for administrator consumption.

The FedEx transaction is the intended first live end-to-end operational test after merge and deployment.
