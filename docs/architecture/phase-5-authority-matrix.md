# Phase 5 Authority Matrix

Transaction clarification is operational when it explains already-recorded package, ACH, instrument, processing, or outcome state without changing that state.

The following classes remain reserved and are escalated instead of executed by the counterparty agent: financing approval; financing-term or amount change; settlement authorization or execution; external-transfer authorization or execution; instrument issuance; ownership transfer; and payment authorization.

Natural-language requests to increase, decrease, revise, modify, or otherwise change the financing are treated as reserved even if the counterparty labels the topic as general processing.

The authority matrix controls mutation, not communication. The agent may acknowledge that a reserved request was received and explain that the recorded transaction remains in effect while authorization is pending.
