# Phase 5 to Phase 6 Handoff

Phase 5 produces durable counterparty cases and responses. Phase 6 should consume those records together with Phase 4 verified outcomes to decide whether an existing workflow can resume, a follow-up action should be scheduled, servicing should be established, or the transaction should remain with the principal because authority or an unresolved exception is outstanding.

Phase 6 must not reinterpret an `AWAITING_AUTHORITY` Phase 5 case as permission to act.
