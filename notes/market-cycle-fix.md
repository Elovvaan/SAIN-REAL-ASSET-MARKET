# Market cycle verification

The public terminal displays complete canonical listing totals from `/api/marketplace-listings/status`, while the visible table remains limited to 100 rows.

The administrator can authorize the current eligible set through readiness and publication in one explicit governed action. The result is re-read from the publication status endpoint and reports the verified live total.

Buy and Sell select an order side and prepare a non-executing SAIN review prompt. They do not create an order, allocation, settlement, ownership recognition, or export package.
